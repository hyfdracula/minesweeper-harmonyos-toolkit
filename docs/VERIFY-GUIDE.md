# 怎么验证（给你看的，不需要懂代码）

手机连上电脑、点亮解锁之后，在 PowerShell 里粘这一行就行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\software\harmony\projects\minesweeper\tools\verify.ps1
```

它会自己完成：装新版本 → 启动 → 依次点一遍菜单、难度、棋盘、爆炸、帮助、统计窗口、插旗、拖动，
每一步都截图，最后把日志里关心的行打出来。整个过程大约 3 分钟，中间**不用你操作**。

跑完截图都在 `D:\software\harmony\projects\minesweeper\docs\verify\`，日志在同一个窗口里。

---

## 脚本管不到的两件事，需要你手动做（各 10 秒）

### 1）双指捏合缩放

真机的手势工具没法模拟两根手指，所以这一项只能你来：

1. 打开扫雷，**两根手指在棋盘上捏一下**（放大或缩小都行）
2. 告诉我一声，我去日志里找 `[Touch] 捏合 档位n=…` 这一行
   —— 有这行就说明捏合被正确识别了，档位数字会跟着变

### 2）折叠屏换屏

1. 在游戏进行中**把手机折起来**（内屏 → 外屏），再展开回来
2. 看两点：棋盘还在不在、计时器数字有没有乱
3. 日志里应该有 `[GameController] 布局` 这一行，把折叠前后的两行都发我

## 如果哪里不对，请这样告诉我

不用描述得专业，只要说清楚**你看到了什么**就行，例如：

- 「点菜单里的高级，还是初级」
- 「结束对话框的按钮点不动」
- 「一进去就闪退」
- 「棋盘跑到右下角去了」

这几种我都能直接定位。最好再附一张截图（截图方法：电源键 + 音量减键）。

## 这次更新了什么（你可以对照着看）

| 变化 | 你应该看到的样子 |
|---|---|
| 新局发牌动画 | 开新局时，方砖从棋盘四角一波波弹起来，约 1 秒 |
| 洪泛涟漪 | 点开一片空地时，格子是一圈圈从点击处扩散出现的 |
| 踩雷爆炸 | 踩到雷先播一段爆炸动画（约 1 秒），**播完才弹**结束对话框 |
| 胜利动画 | 赢了之后一条扫描带从棋盘底部往上扫，雷一个个被光束烧掉，扫完才弹框 |
| 统计信息窗口 | 「游戏 → 最佳成绩」现在打开的是完整窗口：难度列表、最佳时间、六项统计、重置按钮 |
| 帮助 | 「帮助 → 帮助(H)」能打开玩法说明 |
| 应用图标 | 桌面图标换成了原版那颗银色尖刺地雷 |
| 状态条 | `[时钟][计时] …… [雷数][雷图标]`，与真 Win7 一致 |
| 悬停高亮 | 手指按住某格时那格会发光（不是变深青色块） |

## 另外：一条已知的「故意不同」

真 Win7 的第一下只保证「不是雷」，可能直接翻出一个数字；
这个版本是「第一下必定开出一片空地」。这是当初定方案时就拍板的选择，不是 bug。
