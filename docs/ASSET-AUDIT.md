## 0. 先看这一节：两套坐标系，别混

素材里同时存在两套坐标，读错就会取到空白：

| 坐标系 | 定义 | 例子 |
|---|---|---|
| **逻辑坐标（1x）** | 原版 UI XML 的单位，格子边长 = 18。`Theme.ets` / `Theme.h` 里全部用这个 | `RECT_FLAG = [400, 560, 18, 18]` |
| **存储像素（2x）** | PNG 里实际存的像素 = 逻辑坐标 × 2（`SPRITE_SCALE = 2`） | 红旗实际在像素 `x 800..835, y 1120..1155` |

本报告的表格统一给**两列**：逻辑矩形 + 存储像素矩形。

**两个素材根目录是同一套**：`linux-minesweeper-main/assets/` 与 `win7-assets/` 逐文件 SHA-256 一致（32/34 文件相同）；
`win7-assets` 多出 `images/png/Frame.png` 与 `images/png/Minesweeper.png` 两张 PNG 转换版，
且 `png/Frame.png` 与 `Frame.bmp` **逐像素完全相同**，`png/Minesweeper.png` 与 `Minesweeper.bmp` 也完全相同。
所以：`images/png/` 只是 BMP→PNG 的无损转码，**不提供任何新信息**。

## 2. 蓝色 / 绿色主题图集（blueSheet / greenSheet）

### 2.1 结论先行：两图**同构**，绿色主题的工程量极小

量化对比（`blueSheet.png` vs `greenSheet.png`，逐像素）：

| 区域（存储像素） | RGB 差异（>10 的像素占比） | 平均最大差 | alpha 差异像素 |
|---|---|---|---|
| 砖块渐变区 `x 0..900, y 0..1044` | **99.3 %** | 128.5 | 3 884 |
| 已翻开凹陷格区 `x 1000..1900, y 0..1044` | 87.2 % | 31.4（浅色偏色） | 0 |
| 计数器面板 `x 0..120, y 1155..1206` | 43.3 % | 43.0 | 592 |
| 空白沟槽 `x 900..1000` | **0 %** | 0.0 | 0 |
| 数字 1..8 `x 1990..2034, y 0..1044` | **0 %** | 0.0 | 0 |
| 底部覆盖层条 `x 780..1000, y 1110..1170` | **0 %** | 0.0 | 0 |

外加：两图的 alpha 通道在 2 452 782 个像素里只有 4 476 个不同（且全部集中在砖块区）。

**含义**：
- 绿色主题**不是**「再画一套素材」，而是**同一张图集换了个色板**。
- 数字、旗、问号、高亮、红叉、阴影条、空白沟槽**全部逐字节相同**，绿色主题下直接复用，不需要第二套图。
- 唯一需要按主题切换坐标的地方是**拆雷（胜利）动画**：蓝色帧在逻辑 `x = 0`，绿色帧在逻辑 `x = 364`，其余完全一样。

**绿色主题的工程量估计：约 10~15 行**
1. `rawfile/` 增拷 `greenSheet.png`（+2.4 MB）
2. `Theme.ets` 加一个 `BoardStyle` 枚举（或 `boardStyle: 'blue' | 'green'` 字段）
3. `disarmRect(frame)` 加一个 baseX 参数：蓝 = 0，绿 = 364（**这是唯一必须改的坐标**）
4. `SpriteAtlas.boardSheet` 按主题选 `blueSheet.png` / `greenSheet.png`（或者两张都加载，切换时换引用）
5. 加一个「外观」设置项（开关 / 单选）

1. 状态条零件被画在**左上角**，而 Win7 真实版式是**底部**（见 §5.6 的 helpBoard.png）；
2. 边框是 Aero 玻璃渐变，**不是九宫格可拉伸的对称素材**；
3. 该图里**没有笑脸按钮**，也没有完整的状态条底板。

**替代方案（本项目现做法是对的）**：不加载 Frame.png，用纯色画窗口外圈 + 棋盘区，状态条零件分别从 `otherSheet`（时钟）和 `minesweeperSheet`（雷钮）取，笑脸从 `helpBoard.png` 抠（工程已经这么做了，见 `rawfile/face.png`）。

### 5.6 helpBoard.png（256×192）—— 真 Win7 帮助窗口插图

不是一张"帮助文档图"，而是**整个 Win7 扫雷窗口的缩略插图**：

- 上部：**蓝色棋盘**，若干已翻开的格子上带彩色数字（1 蓝 / 2 绿 / 3 红 …），右下角还有一块深色区域；
- 下部：**状态条**，从左到右依次是
  `[ 圆形按钮A ][ 蓝色 LED "18" ]  ……  [ 蓝色 LED "-40" ][ 圆形按钮B ]`

**把两个圆钮放大 14 倍后辨认（见 `docs/audit_helpboard_lefticon.png` / `audit_helpboard_righticon.png`）**：
- **按钮A = 时钟**（钟面 + 指针），**不是笑脸**；
- **按钮B = 地雷**（银圆钮里装一颗雷，与 `minesweeperSheet.png` 的 `RECT_PANEL_MINE` 同款）。

**数字语义**：左边 LED 是 `18`（只能是计时秒数），右边 LED 是 `-40`（只能是雷数计数，插旗插多了 40 面）。
→ 所以真 Win7 的状态条是 **`[时钟][计时 LED] …… [雷数 LED][地雷图标]`**。

> **这条纠正了工程里的一个注释错误**：工程 `Theme.ets` 把从本图抠出的 14×14 左按钮称为「笑脸按钮」，
> 并据此写「左侧 [笑脸][雷数面板] …… [计时面板][雷图标]」。**抠出来的其实是时钟**，
> 因此工程的状态条两个 LED 与真 Win7 **左右相反**。详见 `WIN7-FEATURE-GAP.md` §3.12。

视觉：`docs/audit_helpBoard_full.png`（256×192 放大）。

### 5.7 Minesweeper.bmp / png（144×468）—— 原始大图集，**已被拆包成三张 sheet**

这是 Win7 原始资源里那张密排图集，内容包括：

- 左上角：**蓝色方砖上的问号**、**插旗并带数字**的格子；
- 一列：**纯数字 1..8**（浅底上）；
- 左下：**红叉（错旗）+ 数字**；
- 右侧大块：**方砖 × 「?」叠加 × 旗叠加 × 红叉叠加** 的完整矩阵，**蓝、绿两套并排**。

`build_sheets.py`（linux 复刻里的打包脚本）把它拆成了 blueSheet / greenSheet / minesweeperSheet / otherSheet。
**结论：这是上游源图，本项目不需要它**；但它是**核对拆包是否有遗漏**的唯一权威 —— 若将来怀疑某块素材缺失，回头查这张图。

视觉：`docs/audit_Minesweeper_bmp_full.png`。

## 6. 应用图标建议（HarmonyOS AppScope）

### 6.1 能不能直接用 `icons/MineSweeper-128.png`？

**结论：可以作为 AppScope 图标的「素材来源」，但不建议原样直接用；建议基于它做一次适配。**

依据：

| 检查项 | 实测 | 评价 |
|---|---|---|
| 尺寸 | 128×128 | **符合** HarmonyOS AppScope 图标常用规格（`resources/base/media` 里的 `startIcon.png` 一般 216×216 或 192×192，128 偏小但可缩放） |
| 透明通道 | **有**（alpha 0~255，四角 alpha=0 且 RGB 清零） | 合格，是带透明背景的 PNG，不是「白底方块」 |
| 构图 | 尖刺地雷球居中，占包围盒 `x 8..125, y 6..127` | **问题所在**：包围盒几乎贴满 128×128 画布，尖刺顶端到边缘只剩 2~3 px |
| 圆角/圆形裁切 | — | **会被切掉**。HarmonyOS 桌面图标是圆形/圆角遮罩，尖刺球在圆形遮罩下四角会被削；128 那张的尖刺已经顶到边，圆切必然切尖 |
| 投影 | 图自带柔和投影（在包围盒内） | 投影跟着图标一起被遮罩裁切，观感会变脏 |
| 色彩 | 纯灰银渐变，无品牌色 | 在桌面上辨识度中等 |

### 6.2 建议做法

1. **取 128 那张当底**，重新构图：把地雷球**缩小到画布 70~75 %**（四周留 12~15 % 余量），让尖刺完全落在圆形遮罩安全区内；
2. **去掉自带投影**（或改成很轻的），投影由系统遮罩/阴影提供；
3. 备一张 **216×216 或 512×512 的 `startIcon.png`**（工程现在有 `resources/base/media/startIcon.png`，88 052 字节，需确认它是不是已经是现成的地雷球）；
4. `icons/MineSweeper-48/64.png` 可作背景/市场截图用，**但它们是从 128 缩下来的，不适合当主图标**。

**工作量**：若只求「能上」，直接把 `MineSweeper-128.png` 拷成 `startIcon.png` 即可（0 行代码）；若要求桌面观感正常，需一次图像重排（不改工程代码，在图片层面做，约 10 分钟手工）。

**注意**：`Minesweeper.ico` 只有 32×32，**不要**用它生成大图。
