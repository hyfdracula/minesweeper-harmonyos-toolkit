## 1. 还需要你手动确认的（4 件）

每一件都写了「算什么通过」「算什么失败」「失败了发什么回来」。

### 1.1 声音（代码写了，但没人听过响不响）

**做什么**：开一局（菜单「游戏 → 新建」或按 F2），然后依次做三件事，每做一件停一下听：

1. 点开一格 —— 应有「翻开」的一声
2. 长按插一面旗 —— 应有「插旗」的一声
3. 故意踩一个雷 —— 应有「爆炸」的一声

- **算什么通过**：至少一声能听见，而且**不叠音**、不刺耳。
- **算什么失败**：**一声都没有**；或者声音重叠在一起糊成一片；或者声音又长又不停。
- **失败了发什么回来**：说一声「我什么都没听到」/「声音叠在一起」就行，**不用截图**。

> 如果只是「没听清」，请在**安静的环境**再试一次再报。

### 1.2 双指捏合缩放

**做什么**（三小步，每步都照做）：

1. 在棋盘上**双指张开**（像放大照片），一直张开到最大，等 1 秒
2. 再**双指捏拢**（像缩小照片），捏到最小，等 1 秒
3. 捏到小之后，**一根手指按住棋盘往左拖**，再往右拖

- **算什么通过**（三条都要满足）：
  1. 格子**明显变大又变小**，而且格子**始终是方的**（没被拉扁）
  2. 捏到最小的时候，**整盘棋基本能看全**
  3. **单指拖动，棋盘跟着手指走**，能看到原本在屏外的那些格子
- **算什么失败**：捏了没反应；或者格子变形；或者拖不动、或者一拖就「飞」出去找不回来。
- **失败了发什么回来**：**捏之前**和**捏之后**各截一张图（两张都要），加上第 3 节的日志。

> 30 列的局在竖屏上装不下，程序会**故意**让棋盘超出屏幕边，靠拖动看 ——
> 这是**设计如此**，不是溢出 bug。

### 1.3 横屏 ↔ 竖屏切换（平板特有）

**做什么**：

1. **竖屏**开一局，做三件事：**点开中间一格**、在两个没翻开的格子上**长按插旗**、
   然后**等计时跑到 5 秒以上**
2. 把平板**横过来**（或直接转屏幕），等 2 秒，看四条：
   - 翻开的格子**还是翻开的**
   - 那两面红旗**还在**（还是红旗，不是问号）
   - 计时**继续在走**（不是从 0 开始，也没停住）
   - 雷数**还是原来的数**（没回到 10）
3. **再转回竖屏**，等 2 秒，看同样那四条
4. 横屏画面再看一眼：**菜单栏在左上、棋盘在中间、状态条在底部，三样都在屏内**，格子不歪

- **算什么通过**：第 2、3 步的**四条全部保持住**；第 4 步三样都在屏内、格子不歪。
- **算什么失败**：任何一条不满足（旗没了、计时归零、雷数重置、翻开的格子合上了）、
  或者有任何一块被**裁掉**、或者格子被拉扁。
- **失败了发什么回来**：**横屏那一屏**和**转回竖屏那一屏**两张截图（都要），加第 3 节的日志。

### 1.4 局终后关框，再点棋盘（2026-11-04 新功能）

**背景**：这一条是**我们自己加的增强**，不是原版行为 ——
原版 Win7 局终之后棋盘是**锁死**的，只能用菜单「游戏 → 新建」或 F2 重开。
加它是因为：局终后棋盘本来是死的，而 Win7 状态条上又没有笑脸按钮，
在**不碰菜单**的前提下没有第二条路重开，容易被当成应用卡住。

**做什么**：

1. 故意踩一颗雷 → 失败框弹出来
2. 点失败框**标题栏右上角的红叉**（或「再玩一局」）→ 框关掉
3. **点棋盘任意一格** → 应当**立刻开一局新的**（棋盘全盖上、计时归零、雷数回到 10）
4. 再点刚才那一格 → 应当**正常翻开**

- **算什么通过**：第 3 步开出了新局，第 4 步那一格**正常翻开**（不是没反应）。
- **算什么失败**：第 3 步点了棋盘**什么反应都没有**；或者第 4 步第一下点不开（被当成双击吃掉了）。
- **失败了发什么回来**：**关框后**和**点棋盘后**各截一张图（两张都要），加第 3 节的日志。

## 2. 不用报、属于原版就这样的

## 3. 怎么抓日志（hilog）

在 DevEco Studio 的 **Log** 窗口里选设备 `3KQYD25331202962`，
搜 `com.example.saolei`，把复现那几秒的日志截下来即可。

命令行版：

```powershell
$hdc = 'D:\software\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc -t 3KQYD25331202962 shell "hilog -x"   # 读并清空缓冲区
```

日志里跟这几个关键字有关：

| 关键字 | 什么时候出现 |
|---|---|
| `[GameController] 布局 画布=…` | 每次画布尺寸变化（换屏、横竖屏切换） |
| `[Dialog] 打开 …` / `[Dialog] 点击按钮 …` | 结算框弹出 / 框上的按钮被点到 |
| `[Game] 局终后点棋盘：重开一局` | 2026-11-04 新功能被触发（你手动点棋盘重开时） |
| `[Touch] 平移 dx=… dy=…` | 单指拖动棋盘 |
| `[MinefieldCanvas] 取屏 … 的密度失败` | 换屏时取密度出问题（出现这个要报） |
